# Excel Sales Dashboard

## Project Overview
This project is an interactive Sales Dashboard created using Microsoft Excel to analyze sales performance and identify business trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

## Dashboard Features
- Total Sales Analysis
- Monthly Sales Trends
- Region-wise Sales Performance
- Top Performing Products

## How to Use
1. Download the Excel file.
2. Open it in Microsoft Excel.
3. Use the slicers and filters to explore the dashboard.
